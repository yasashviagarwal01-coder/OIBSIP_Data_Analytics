# Task 1: Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, profit distribution, customer segments, and business insights using Python.

## 🎯 Objectives
- Understand the dataset
- Perform data cleaning
- Analyze sales and profit trends
- Visualize important business metrics
- Generate actionable business insights

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Files Included
- `Task1_Retail_Sales_EDA.ipynb`
- `sample_-_superstore.xls`

## 📈 Key Insights
- Technology category generated the highest sales and profit.
- West region recorded the highest sales.
- Discounts negatively affected profitability.
- Top-selling products and customer segments were identified.

## 📌 Conclusion
The analysis provides useful insights that can help improve sales performance and business decision-making.
